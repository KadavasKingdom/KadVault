# Kad Vault
Creates a vault in PT-00 which uses a special custom item to open. Treasure awaits those who make the perilous journey to open the vault.

What's in this plugin **for you:**
- Framework to learn how Project MER works (https://discord.gg/JwAfeSd79u)
- Spawning system for random items ontop of Project MER spawnpoints (default Unity spawn points don't work for using loot tables, instead I created a system that randomly picks items as they're assigned)

What this plugin doesn't have **for you:**
- Free schematics for the vault
- Free custom items or chaotic coins
- Free SFX
- A .dll to use the plugin, if you aren't a plugin **developer** there's nothing here for you (sorry!)
_This plugin is made public for people to learn, to pick and choose from. **DO NOT** expect this plugin or any of its dependencies to be maintained for your use, it's intended for private use on the Kadava's Calamity game server._
